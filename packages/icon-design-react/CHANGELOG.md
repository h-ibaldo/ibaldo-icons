## [0.1.0] - 2026-02-14

### Added
- Initial release of @icon-design/react
- 1,485 line-based SVG icons as React components
- Full TypeScript support with .d.ts definitions
- Dual module format (ESM + CJS)
- Tree-shaking support (sideEffects: false)
- Forward ref support for all components
- Customizable props: size, color, strokeWidth, className
- Individual icon imports for optimal bundle size
- PascalCase component naming (e.g., UserCircle, ArrowLeft)

### Package Details
- Distribution size: 37MB
- Module formats: ESM (`dist/esm/`) and CJS (`dist/cjs/`)
- TypeScript definitions included
- React 16.8.0+ peer dependency
