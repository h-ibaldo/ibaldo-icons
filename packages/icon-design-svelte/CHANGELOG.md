## [0.1.0] - 2026-02-14

### Added
- Initial release of @icon-design/svelte
- 1,485 line-based SVG icons as Svelte components
- Full TypeScript support with .svelte.d.ts definitions
- ESM module format (native Svelte)
- Tree-shaking support (sideEffects: false)
- Svelte 3, 4, and 5 compatibility
- Customizable props: size, color, strokeWidth, class
- Rest props support via $$restProps
- Individual icon imports for optimal bundle size
- PascalCase component naming (e.g., UserCircle, ArrowLeft)

### Package Details
- Distribution size: 24MB
- Module format: ESM only (`dist/`)
- TypeScript definitions included
- Svelte 3.0.0+ peer dependency
